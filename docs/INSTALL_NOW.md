## 📱 اختبار الإشعارات الآن (على الجوال)

1. افتح على الجوال: **https://messenger-gamma-five.vercel.app/**
2. سجّل الدخول بحسابك (`admin@sharaf.com`)
3. الإعدادات ⚙️ → **«تفعيل إشعارات الجهاز»** → اضغط **السماح**
4. تحقق أن رمزك ظهر في جدول `fcm_tokens` (أستطيع فحصه لك إن أردت)
5. من **حساب ثانٍ** (بريد آخر) ابدأ محادثة معك وأرسل رسالة → يجب أن يصل التنبيه

> 📱 **آيفون:** لا تعمل الإشعارات في Safari إلا بعد `مشاركة → إضافة إلى الشاشة الرئيسية` (iOS 16.4+).
> **أندرويد/كروم:** تعمل مباشرة.
> ⚠️ إن ظهر خطأ عند التفعيل: اخرج وادخل من جديد ثم أعد المحاولة (الـ Service Worker يحتاج تحميلاً جديداً).

## 🔴 المتبقي — خطواتك

### 1. سجّل بقية المشرفين ثم أرقّيهم

سجّل الحسابات بنفس الإيميلات المكتوبة في القائمة، ثم أخبرني لأُرقّيها دفعة واحدة:

```
111@admin.com · 222@admin.com · 333@admin.com · 444@admin.com · 555@admin.com
```

> ⚠️ **تنبيه مهم:** أي بريد في القائمة لا تملك صاحبه **لن يستطيع استعادة كلمة مروره**
> إن نسيها (لا يصل التحقق). إن كانت هذه أسماء مؤقتة، أزلها من القائمة ودع كل
> شخص يسجّل ببريده الحقيقي، ثم أضيفه خلال ثوانٍ.

**لإضافة مشرف جديد (بعد تسجيله):**
```sql
-- أضف بريده إلى القائمة ثم شغّل الترقية
update public.profiles set is_admin = true where lower(email) = 'newadmin@example.com';
```

### 2. 🔑 أمن المفتاح الذي أرسلته

المفتاح الآن محفوظ في أسرار Supabase (وهذا هو مكانه الصحيح). لكن بما أنه مرّ في محادثة،
الأفضل **تدويره** بعد أن تتأكد أن كل شيء يعمل على جهازك:

```
1) Firebase → Project settings → Service accounts
2) ستجد المفتاح بمعرّفه 2c6174f5… → Delete
3) Generate new private key  → أرسل الملف الجديد → أحدّث الأسرار
```
أو اتركه — لا خطر عاجل، لكن التدوير ممارسة سليمة. وأخبرني إن أردت أن أتولى التحديث.

## 💬 الرد التلقائي (رسالة الترحيب بالأزرار) — مُفعَّل

عندما يفتح مستخدم عادي محادثة مع مشرف، يُرسل النظام تلقائياً رسالة من المشرف
وتحتها أزرار جاهزة، وضغط الزر يُرسل نصّه كرسالة.

**الوضع الحالي في مشروعك:**

| الإعداد | القيمة |
|---|---|
| مُفعَّل | ✅ نعم |
| النص | `مرحباً 👋 كيف يمكننا مساعدتك؟ اختر أحد الخيارات أو اكتب رسالتك مباشرةً.` |
| الأزرار | 🛠️ طلب دعم فني · 💬 استفسار عن خدمة · 📄 شكوى |

> ℹ️ كانت هذه الميزة موجودة في الواجهة أصلاً (`js/app.js:1893` يعرض الأزرار،
> `js/app.js:1981` يتعامل مع الضغط، و`css/style.css:1757` تنسيقاتها) لكن كان
> ناقصاً: **عمود `messages.buttons`** و**آلية الإرسال التلقائي** — وقد أُكملا في
> `sql/auto_reply.sql` بنفس آلية المشروع (Trigger بصلاحيات definer).

### ✏️ تغيير النص والأزرار

```sql
update public.auto_reply_settings
   set greeting = 'أهلاً بك 👋 كيف نساعدك اليوم؟',
       buttons  = '[
         {"label":"🛠️ دعم فني","value":"طلب دعم فني"},
         {"label":"💰 الأسعار","value":"استفسار عن الأسعار"},
         {"label":"📄 شكوى","value":"لدي شكوى"}
       ]'::jsonb,
       updated_at = now();
```
> `label` = ما يظهر على الزر · `value` = ما يُرسل كرسالة عند الضغط.
> ويمكن جعل `value` مختلفاً عن `label` (مثلاً زر «🛠️ دعم فني» يرسل «طلب دعم فني»).

### ⏸️ إيقافه مؤقتاً

```sql
update public.auto_reply_settings set is_enabled = false, updated_at = now();
```

### سلوك الميزة

- تُرسل **مرة واحدة** لكل محادثة جديدة (عبر Trigger على `conversations`).
- **لا** تُرسل في محادثة بين مشرفين — للمستخدم العادي وحده.
- المشرف المرسل هو **صاحب المحادثة** (`admin_id`) لا مشرف عشوائي.
- تُحدَّث قائمة المحادثات الجانبية بنص الترحيب فوراً.
- لا يستطيع أي مستخدم إرفاق أزرار برسالته (العميل ممنوع، النظام فقط) —
  لأن ذلك يسمح بإظهار أزرار مضلِّلة في واجهة الطرف الآخر.
- غير المشرف لا يستطيع تعديل نص الترحيب.
